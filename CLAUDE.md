# trace

Статический сайт: `index.html` + `style.css` + `script.js`, без сборки и зависимостей.

Репозиторий: https://github.com/moogychi/trace (ветка `main`) — **публичный** по просьбе пользователя,
включён GitHub Pages: https://moogychi.github.io/trace/ (обновляется сам после каждого пуша в `main`).
Это исключение из общего правила о приватных репозиториях — только для этого проекта.
В коммитах — скрытый email GitHub (`...@users.noreply.github.com`, задан в настройках этого репозитория);
личные данные в код и коммиты не добавлять: всё видно публично.
Смотреть сайт — по ссылке выше или локально через Live Server.

## Правила работы с git

- После каждого завершённого изменения делай коммит и сразу пушь в `main` (`git push origin main`).
- Сообщение коммита пиши на русском: коротко и понятно, что изменилось и зачем (например, «Добавлен раздел с проектами»).
- Один коммит — одно логическое изменение; не смешивай несвязанные правки.
